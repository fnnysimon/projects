# D. Stress-test the idea

Status: to do · [Back to the method](../README.md)

**Goal:** find the weak points before building.

**What we do**
- Run `/debatexperts`: three expert profiles attack the idea ("is this really a problem?", "is the estimate reliable?").
- Keep the objections that hold and write a stronger V2 of the spec.

**Output:** the debate summary and the V2 changes.
