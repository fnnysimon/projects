# B. Prove the need

Status: in progress · [Back to the method](../README.md)

**Goal:** show that estimating cost before deploying is a real need, not only ours.

**What we do**
- Gather GitHub issues and comments about credits and cost ([#9620](https://github.com/simstudioai/sim/issues/9620) and others).
- Write down the questions users actually ask.
- Run `/ux-superpowers`, scoped to the job "estimating an agent's cost before deploying it": persona, jobs to be done, insights.

**Output:** evidence table, persona, jobs to be done, key insights.
