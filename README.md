# projects
all projects I involved

## Projects

- [SIM amélioré](sim-ameliore/): a test copy of [Sim](https://github.com/simstudioai/sim) (YC startup, open source under Apache 2.0), a visual workspace for building AI agents, used to practise UX/UI improvements on a real product with Claude Code. Includes a UX discovery report, a design critique and an interaction spec, each turned into code (see [ux-audit/](sim-ameliore/ux-audit/)), and a before/after report with annotated screenshots made with the `/doc` skill ([PDF](sim-ameliore/doc/sim-ameliore-report.pdf)). Not affiliated with Sim Studio: tests only
- [Tova M1 redesign](tova-m1-redesign/): a deliberately broken robot landing page, inspired by of [Nori.A3](https://www.norirobotics.com/), fixed step by step with Claude skills. Includes a before/after report and screenshots. Unaffiliated exercise
- [Nimbus](nimbus/): a landing page with a design system broken on purpose, improved step by step with Claude skills. Includes a 41-page before/after report with annotated screenshots, made with the `/doc` skill. Unaffiliated exercise
- [GooseWorks](gooseworks/): an editable recreation of [gooseworks.ai](https://gooseworks.ai/) (YC startup), improved step by step with Claude skills: design critique, design elevation, UX discovery, booking-flow interaction design, and fewer clicks on every path to booking (8.0 → 5.8 on average), and a shorter mobile page (12.9 → 8.6 screens). Includes a 33-page before/after report with annotated screenshots, made with the `/doc` skill. Unaffiliated exercise
